# git-tracker

Pequeña herramienta para rastrear commits y actividad en repositorios Git.


## Instalación

Instala con uv desde el directorio del proyecto o desde PyPI si está publicado:

```bash
uv sync
```

## Uso

Ejemplos básicos de uso y scripts de prueba están en la carpeta `scripts/`.

1. Obtén un reporte de commits de los usuarios a los que sigues
```bash
just stalk
```
